## 💡 India-Specific SEO Best Practices

### **1. Mobile-First Optimization**
- **Why:** 90%+ of Indian users access via mobile
- **Action:** Ensure fast loading times (< 3 seconds)
- **Action:** Use mobile-responsive design
- **Action:** Optimize images for mobile bandwidth

### **2. Include Pricing & Currency**
- **Why:** Price is a major decision factor for Indian customers
- **Action:** Use ₹ (Indian Rupee) symbol in titles and descriptions
- **Action:** Include terms like "affordable", "budget-friendly", "best price"
- **Action:** Mention specific prices when possible

### **3. Highlight Delivery Benefits**
- **Why:** Delivery is a key concern for online shoppers
- **Action:** Mention "Free shipping in India"
- **Action:** Include "Fast delivery" or "Pan-India delivery"
- **Action:** Specify delivery timeframes (e.g., "2-3 days")

### **4. Use Location Keywords**
- **Why:** Local search is important in India
- **Action:** Include "India" or "Indian" in keywords
- **Action:** Consider regional keywords (Delhi, Mumbai, Bangalore, etc.)
- **Action:** Use "Made in India" if applicable

### **5. Social Media Optimization**
- **Why:** WhatsApp, Facebook, Instagram are primary sharing platforms
- **Action:** Create 1200x630px OG images
- **Action:** Include brand name and key message in images
- **Action:** Use engaging, action-oriented descriptions
- **Action:** Optimize for WhatsApp sharing (text preview)

### **6. Long-Tail Keywords**
- **Why:** Specific phrases have higher conversion rates
- **Action:** Use phrases like "buy 3D printed gifts online India"
- **Action:** Include problem-solving keywords
- **Action:** Target specific product combinations

## 📋 SEO Field Guidelines

### **Meta Title (60 characters max)**
- Include: Brand name, main keyword, location, unique value
- Example: "SparkleSphere - 3D Printed Products India | ₹ Affordable"
- Avoid: Keyword stuffing, misleading claims

### **Meta Description (150-160 characters)**
- Include: Main keyword, location, value proposition, CTA
- Example: "Discover premium 3D printed products & custom designs in India. Fast delivery, affordable prices. Shop now!"
- Avoid: Duplicate descriptions, missing keywords

### **Meta Keywords**
- Include: 5-10 relevant keywords
- Include: Long-tail keywords
- Include: Location-based keywords
- Avoid: Unrelated keywords, keyword stuffing

### **OG Image (1200x630px)**
- Include: Brand name/logo
- Include: Key message or product image
- Include: Call-to-action
- Avoid: Text-heavy images, low resolution
