# 🇮🇳 India SEO Quick Reference Card

## 🎯 Quick Start (5 Minutes)

### **Step 1: Go to Admin Panel**
Navigate to: `/admin/seo`

### **Step 2: Select Page Type**
Choose one of:
- **Homepage** - Main site SEO
- **Product** - Product page template
- **Category** - Category page template

### **Step 3: Apply Defaults**
Click: **"Apply All India-Optimized Defaults"**

### **Step 4: Customize**
- Replace placeholders with your content
- Add specific product names or categories
- Include regional keywords if needed

### **Step 5: Save**
Click: **"Create SEO Settings"**

---

## 📝 Essential Elements

### **Meta Title (60 chars max)**
```
✅ Good: "SparkleSphere - 3D Printed Products India | ₹ Affordable"
❌ Bad: "Welcome to our website"
```

**Must Include:**
- Brand name
- Main keyword
- Location (India)
- Unique value (₹, Free shipping, etc.)

### **Meta Description (150-160 chars)**
```
✅ Good: "Discover premium 3D printed products & custom designs in India. 
Fast delivery, affordable prices. Shop now!"
❌ Bad: "This is a website about 3D printing"
```

**Must Include:**
- Main keyword
- Location (India)
- Value proposition
- Call-to-action

### **Meta Keywords**
```
✅ Good: "3D printing India, custom 3D printed products, personalized gifts India"
❌ Bad: "3D, printing, products, India, shop, buy, online"
```

**Must Include:**
- 5-10 relevant keywords
- Long-tail keywords
- Location-based keywords

## 💰 India-Specific Keywords

### **Always Include:**
- ₹ (Indian Rupee symbol)
- "India" or "Indian"
- "Affordable" or "Budget-friendly"
- "Free shipping" or "Fast delivery"

### **Examples:**
- "3D printing India"
- "Custom 3D printed products"
- "Personalized gifts India"
- "Affordable 3D printing"
- "Buy 3D printed items online India"

## 🎯 Content Templates

### **Homepage Title Template**
```
[Brand] - [Main Keyword] [Location] | ₹ [Value Prop]
```
Example: "SparkleSphere - 3D Printed Products India | ₹ Affordable"

### **Homepage Description Template**
```
[Value Prop] [Main Keyword] & [Secondary Keyword] in [Location]. 
[Benefit 1], [Benefit 2]. [CTA]!
```
Example: "Discover premium 3D printed products & custom designs in India. 
Fast delivery, affordable prices. Shop now!"

### **Product Title Template**
```
[Product Name] - [Keyword] | [Location] | [Brand]
```
Example: "Custom 3D Printed Figurine - Personalized Gift | India | SparkleSphere"

### **Product Description Template**
```
Buy [Product] - [Value Prop] with [Feature]. [Delivery Info]. ₹[Price]. [CTA]!
```
Example: "Buy Custom 3D Printed Figurine - Premium quality with custom design options. 
Free shipping in India. ₹999. Order now!"

## 💡 Pro Tips

1. **Use Long-Tail Keywords** - "Buy 3D printed gifts online India" converts better than "3D printing"

2. **Include Price** - Mention ₹ symbol and price range in descriptions

3. **Highlight Delivery** - "Free shipping in India" is a major selling point

4. **Mobile First** - 90%+ of Indian users are mobile

5. **Social Sharing** - Optimize OG images for WhatsApp, Facebook, Instagram

6. **Local Keywords** - Include city names (Delhi, Mumbai, Bangalore) if relevant

7. **Test & Iterate** - Monitor rankings and adjust keywords monthly

8. **Update Regularly** - Refresh content every 3-6 months
